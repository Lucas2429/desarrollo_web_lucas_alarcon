# desarrollo_web_lucas_alarcon

Decidi ocupar una barra de navegación para moverse entre las distintas ventanas de la página para más conveniencia. Por esto mismo, agregue un icono de una casa para volver a la ventana de inicio (home.html), esto es importante decirlo por que se pedia que hubiera una manera de volver al inicio al abrir fotos en las actividades. Hablando de la ventana de actividades, decidi crear una lista donde estarían todas las actividades y para revisar su información hay que presionar donde dice "Actividad 1", por ejemplo. Al hacerlo, se despliega una tabla con la información e imagenes.

Tarea_5:

Para el acceso exclusivo del usuario "admin" con contraseña "examen" a los html "admin-fotos" y "log", se decidio crear un nuevo rol: "ADMINFOTO" que tiene acceso a todo lo que hace un admin cualquiera, pero se incluyen estas vistas. Un admin normal no tiene acceso a estas.

Se decidio usar un formulario para informar el motivo de eliminacion de una foto, que despues es entregado a AdminFotosController para lo que se pide.
